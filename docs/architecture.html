Factory Inventory Management System

A demo full-stack application: Vue 3 single-page frontend, Python FastAPI backend, and in-memory mock data loaded from JSON files. There is no database.

Data Flow

  1. User sets filtersTime period, warehouse, category and order status held as shared refs in useFilters.js.
  2. View requests dataViews call client/src/api.js, which builds query params and sends an axios GET to localhost:8001/api.
  3. FastAPI routes the requestEndpoint handlers in server/main.py receive the query params.
  4. In-memory filteringLists imported from mock_data.py are filtered and aggregated in Python.
  5. Pydantic validationResults are serialised through response models and returned as JSON.
  6. Reactive renderingRaw data lands in refs (allOrders, inventoryItems); computed properties derive the displayed values and charts.

Key notes

Behaviour worth knowing
  • The API base URL is hard-coded to http://localhost:8001/api in api.js.
  • Inventory filters do not support month, as inventory has no time dimension.
  • Data is not persisted; any change to purchase orders is lost on restart.
  • Revenue goals: $800K per month, $9.6M year to date.
  • When the JSON structure changes, the matching Pydantic models must be updated.
